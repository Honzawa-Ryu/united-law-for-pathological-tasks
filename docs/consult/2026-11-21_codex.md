- **最初は BCSS の組織セグメンテーションを1タスク。** Phase 0 → 密予測 → BRACS → WSI の順は妥当です。BCSS は正解マスクが WSM のパレット出力に対応し、核インスタンス分離や ROI 内の弱教師ラベルを持ち込まずに適応性能を測れます。まず100タイルで動作と学習曲線を確認し、同じスライド分割・倍率・教師データで UNI の空間トークン＋軽量デコーダと比較。見込みがあれば500タイルと複数の抽出 seed に進み、PanNuke はその後で十分です。**密予測なら WSM が有利という病理での根拠は、現時点では弱い**です。[BCSS 公式リポジトリ](https://github.com/PathologyDataScience/BCSS) · [WSM 論文 v2](https://arxiv.org/html/2611.24917v2)
- **Phase 0 は A6000 で、公開推論・短い学習・再開まで。** 公開 RGB→depth を少数画像で確認し、BCSS の数枚で過学習できるかを試せば、別の custom タスクを作る手間が省けます。ピーク VRAM、秒/更新、前処理込みの秒/タイル、チェックポイント再開を確認。論文 v2 の代表例は depth が **11.0 A100 時間**、Normal→Human Segmentation が **9.6 A100 時間**です。表の *updates × batch* はユニーク画像数と区別し、4時間枠は再開前提で見積もるのが妥当です。[WSM 論文 v2](https://arxiv.org/html/2611.24917v2)
- **中止基準はタスク別に置く。** 学習前に① H&E の VAE 往復前後で、同じ核検出器の正解注釈に対する核再現率・面積誤差を比較、② 正解パレットマスクを VAE 往復し、実際の色復号で mIoU・境界 F1 を計測。①は入力情報の診断、②は出力表現の診断で、どちらも厳密な性能上限ではありません。核が崩れるなら核タスクを保留し、組織・ROI は各指標で判断します。BCSS では、許容する mIoU 差と推論時間を先に決め、500タイルでも大差が再現し、少数データ・局在・計算費のいずれにも利点がなければ打ち切り。4時間時点で学習曲線が伸びていれば、判定は保留です。[FLUX.2 公式実装](https://github.com/black-forest-labs/flux2)
- **BRACS の第一候補は、分類枝を固定した組織領域で使い、ROI 単位で学習する方法。** 著者の枝は生成された連結領域で条件潜在をマスクし、クラスプロトタイプとのコサイン類似度を計算します。実装で領域を差し替えられるなら、まず固定した組織マスクでクラススコアを取り、複数タイルのスコアを平均または attention pooling して、**ROI ラベルで損失**を取ります。局所的な異型が多数決で埋もれるため、全タイルへの ROI ラベル継承は避けます。画像出力を保つ案 A は、ROI 全体を読める入力で単色パレットを出す対照実験に。固定領域方式の優位性は未検証です。公式分割で UNI/CONCH と入力視野を揃え、macro-F1・クラス別再現率を比較し、HACT-Net の既報値は分割と評価単位が一致する場合に参照します。[WSM の分類枝](https://arxiv.org/html/2611.24917v2) · [BRACS 原著](https://www.iris.unina.it/retrieve/3cce174c-db8c-419c-9b1c-24141b0bc200/BRACS.pdf) · [HACT-Net](https://www.sciencedirect.com/science/article/pii/S1361841521003091) · [UNI](https://doi.org/10.1038/s41591-024-02857-3) · [CONCH](https://www.nature.com/articles/s41591-024-02856-4)
- **引用優先度は Marigold、SegDiff／MedSegDiff、PathSegDiff、Diffusion Classifier。** Marigold は事前学習済み画像生成器の密予測への転用、SegDiff／MedSegDiff はマスク自体の生成、PathSegDiff は病理での拡散特徴＋識別デコーダ、Diffusion Classifier はクラス条件付きの誤差を使う分類の先行例です。実測で優先するのは、**同じデータでの UNI＋軽量ヘッドと、凍結 FLUX 特徴＋軽量ヘッド**。後者を入れると、反復生成を加える価値を測れます。核まで進むなら HoVer-Net または CellViT を加え、Dice に加えて PQ と核の検出 F1 を見ます。[Marigold](https://openaccess.thecvf.com/content/CVPR2024/html/Ke_Repurposing_Diffusion-Based_Image_Generators_for_Monocular_Depth_Estimation_CVPR_2024_paper.html) · [SegDiff](https://arxiv.org/abs/2112.00390) · [MedSegDiff](https://proceedings.mlr.press/v227/wu24a.html) · [PathSegDiff](https://arxiv.org/abs/2504.06950) · [Diffusion Classifier](https://arxiv.org/abs/2303.16203)
- **WSI は案1から。** TG-GATEs でまず注釈の厚い病変を1種類選び、既存の UNI 埋め込み＋MIL を基準に、同じ候補タイルへ WSM の病変面積率・スコアを足したときの増分を測ります。Bayer 注釈で局在を、所見ラベルでスライド判定を評価し、秒/WSI と病変単位の感度も記録。案2は候補抽出の病変再現率を測ってから導入します。低倍率で落とした小病変は後段で拾えません。案3は特徴の空間整列・正規化・入力実装の変更が絡み、現時点で優先する根拠は弱いです。ラット肝の結果から言えるのは、その病変とデータ条件での有用性までです。[CLAM](https://www.nature.com/articles/s41551-020-00682-w)
- **評価と利用条件の落とし穴。** 分割はヒトなら患者、ラットなら個体を単位にし、TG-GATEs で未知化合物への一般化を主張するなら化合物も分離します。少数ショットはタイル数と由来スライド数を併記し、染色・スキャナ・倍率（µm/px）別に確認。VAE の8倍縮小だけで核の保存可否を決めず、小核・接触核・細い境界で往復誤差を測ります。パレット復号・棄却閾値は検証セットで固定し、核では同色の隣接インスタンスが融合する点も評価します。利用条件は FLUX.2、WSM のコード・配布重み・派生トンネル、BRACS、Bayer 注釈ごとに確認してください。FLUX.2 Klein 4B の Apache 2.0 を WSM に適用できるとは限りません。**WSM の配布物に適用されるライセンス本文と、企業内研究・派生重みの共有可否は今回未確認**です。[FLUX.2 公式リポジトリ](https://github.com/black-forest-labs/flux2) · [WSM 配布元](https://huggingface.co/World-Snapshot) · [BRACS 利用条件](https://www.bracs.icar.cnr.it/background/)
