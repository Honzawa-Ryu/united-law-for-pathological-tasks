# 結果のまとめ: WSM（World Snapshot Models v1）を病理画像で試した

最終更新: 2026-11-25。経過の詳細は `docs/PROGRESS.md`、学習手順は `docs/WSM_TRAINING_RECIPE.md`。

## 結論

1. **WSM はコードを変えずに病理画像で学習できる。** FLUX.2 Klein 4B を凍結し、約 1250 万パラメータのトンネルだけを学習する。A6000（48 GB）1 枚で動く。
2. **ROI の分類（BRACS、7 クラス）では、UNI2-h + 線形分類に並ぶが上回らない。** WSM 単体は test の macro-F1 で 0.02〜0.04 下、UNI の特徴を条件に足すと同等。学習に半日、推論に 1 枚 4〜5 秒かかるので、分類だけなら UNI の線形分類を使う。
3. **組織セグメンテーション（BCSS、5 クラス）では、DINOv2 ViT-L + 線形デコーダを test の mIoU で 0.03 上回った。** ただし val では同等で、学習を延ばしても伸びなかった。病理の基盤モデル（UNI）との比較は未実施（重みを取得できなかった）。
4. **学習はバッチサイズに敏感。** 著者の既定（バッチ 1）では分類が不安定で、バッチ 4 で安定した。バッチ 4 は VRAM 44 GB で A6000 の上限。

## BRACS: ROI の 7 クラス分類（公式分割、test 570 枚）

入力は ROI 中央の 1 タイル（512 px。10 倍は 2048 px 四方、20 倍は 1024 px 四方を縮小）。出力はクラス色で塗った画像で、最も近い色の多数決で 1 クラスに読み替える。条件は val（312 枚）で選び、test は各モデル 1 回。

| モデル | val acc / macro-F1 | test acc / macro-F1 |
|---|---|---|
| UNI2-h + 線形（範囲 2048） | 0.657 / 0.647 | 0.611 / 0.600 |
| UNI2-h + 線形（範囲 1024） | 0.692 / 0.673 | 0.590 / 0.573 |
| WSM 20 倍 + UNI、バッチ 4、9000 ステップ | 0.699 / 0.670 | 0.588 / 0.570 |
| WSM 10 倍、バッチ 4、9000 ステップ | 0.628 / 0.598 | 0.574 / 0.557 |
| WSM 20 倍 + UNI、バッチ 4、3000 ステップ | 0.625 / 0.614 | 0.570 / 0.557 |
| WSM 20 倍、バッチ 4、9000 ステップ | 0.651 / 0.636 | 0.561 / 0.545 |
| WSM 10 倍 + UNI、バッチ 4、3000 ステップ | 0.638 / 0.630 | 0.547 / 0.525 |
| WSM 10 倍、バッチ 4、3000 ステップ | 0.577 / 0.535 | 0.537 / 0.499 |
| WSM 10 倍、バッチ 1、3000 ステップ | 0.458 / 0.406 | 未評価 |
| 著者の分類枝（VAE 潜在表現 + CNN）10 倍、3 シード平均 | 0.523 / 0.498 | 0.426 / 0.400 |
| 著者の分類枝（VAE 潜在表現 + CNN）20 倍、3 シード平均 | 0.450 / 0.422 | 0.415 / 0.382 |

- UNI + 線形は、NAS にあった UNI2-h のパッチ埋め込み（TRIDENT、20 倍 256 px）を WSM の入力と同じ範囲で平均し、ロジスティック回帰にかけたもの（実験 0007）。正則化の強さは格子の端が選ばれており、調整は粗い。
- バッチ 4 では学習を延ばすと伸びる（20 倍: 3000 → 5500 → 9000 ステップで val macro-F1 0.465 → 0.534 → 0.636）。バッチ 1 では伸びない（10 倍: 3000 → 5000 で 0.406 → 0.384）。
- 倍率（10 倍と 20 倍）の優劣は val と test で入れ替わり、決められない。
- 推論はシードに対して安定（同じモデルを 3 シードで評価して acc が一致）。
- 検証損失（生成の誤差）は分類精度の目安にならない。条件の選択は val の分類精度で行う。
- どのモデルも test は val より 0.04〜0.10 低い（UNI + 線形も同じ傾向）。
- **著者の分類枝（実験 0013）は、色の多数決方式より test の macro-F1 で 0.15 前後低い。** 論文 3.6 節の構成で、入力画像の VAE 潜在表現だけを見る約 154 万パラメータの CNN。トンネルも生成結果も使わない（著者の構成では生成結果は領域の形を決めるだけで、BRACS は画像全体が 1 クラス）。学習データに過適合し、シード間の test macro-F1 は 10 倍で 0.382〜0.429。組織型の分類には VAE の潜在表現と小さな CNN では足りず、FLUX.2 本体を通す色の多数決方式のほうが良い。

## BCSS: 組織の 5 クラスセグメンテーション（施設単位の分割、test 450 タイル）

入力は 20 倍相当（0.5 µm/px）の 512 px タイル。出力はクラス色で塗り分けた画像で、画素ごとに最も近い色へ読み替える。

| モデル | val pixel acc / mIoU | test pixel acc / mIoU / 平均 Dice |
|---|---|---|
| WSM、バッチ 4、6000 ステップ | 0.794 / 0.561 | 0.808 / 0.611 / 0.751 |
| DINOv2 ViT-L/14 + 線形デコーダ | 0.783 / 0.569 | 0.795 / 0.580 / 0.727 |

- test のクラス別 IoU（WSM / DINOv2）: tumor 0.786 / 0.749、stroma 0.675 / 0.676、inflammatory 0.594 / 0.541、necrosis 0.602 / 0.534、other 0.398 / 0.402。
- WSM は 1750 ステップ時点で val の mIoU 0.568 に達し、6000 ステップまで延ばしても変わらなかった。
- 比較対象は線形の層 1 枚で、学習は 4 分。最良エポックが最終エポックだったので、延ばせば上がる可能性がある。
- test の施設の組（OL、LL、E2、EW、GM、S3）は記憶に基づく指定で、公式ベースラインのページでの確認が済んでいない。既報値との比較はしていない。

## コスト（A6000 1 枚）

| 項目 | WSM | 比較対象 |
|---|---|---|
| 学習 | バッチ 4 で約 5.3 秒/ステップ。3000 ステップで約 4.5 時間、9000 ステップで約 13 時間 | UNI 特徴 + ロジスティック回帰は数分。DINOv2 + 線形デコーダは 4 分 |
| 推論 | 512 px タイル 1 枚あたり 4.3〜4.7 秒（10 ステップ） | DINOv2 の特徴抽出は 0.07 秒/タイル |
| VRAM | 推論 15 GB、学習はバッチ 1 で 18 GB、バッチ 4 で 44 GB | — |

WSI 1 枚が 1 万タイルなら、WSM の推論は約 12 時間かかる計算になる。

## 学習なしで確かめたこと（Phase 0）

- FLUX.2 の VAE に H&E 画像を往復させても、情報はよく残る（40 倍で PSNR 33.7、核領域の一致度 0.94。実験 0003）。
- 二値マスクの往復もほぼ無損失（Dice 0.999）。出力をパレット画像にする方式は、表現の面では問題にならない。

## まだ分かっていないこと

- UNI + 軽量デコーダとのセグメンテーション比較（UNI2-h の重みが必要）。
- WSI 全体への拡張（未着手）。推論コストが最大の制約になる見込み。
- 少数ショットでの比較（学習データを 100 / 500 枚に絞った場合）。計画にあったが未実施。
- 既報値との比較（BRACS、BCSS とも、分割と評価単位の一致を確かめていない）。
- 関連研究の一次確認（`docs/RELATED_WORK.md` の「未」）。
